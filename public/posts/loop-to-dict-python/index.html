Mari Berkenalan dengan Dict Python

July 9, 2026
Categories: Programming

JSON cukup populer di dunia programming tak terkecuali pada bahasa pemrograman Python. Di Python ada tipe yang sangat mirip dengan JSON yaitu dict. Dict (singkatan dari Dictionary) terdiri dari pasangan key dan value. Contohnya seperti ini :

kamus = {
	"id": 1,
	"nama":"Budi"
	}

Pada contoh di atas, id dan nama adalah contoh key, sedangkan 1 dan Budi adalah value-nya. Dict bisa berisi lebih dari satu pasang id dan nama. Seperti ini :

kamus2 = [
		{"id": 1, "nama": "Budi"},
		{"id": 2, "nama": "Cindy"},
		{"id": 3, "nama": "Danu"}
	]
