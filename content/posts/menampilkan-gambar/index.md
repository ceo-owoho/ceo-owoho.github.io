## Menampilkan Gambar

![foto kami](myfam.png)

Untuk bisa menampilkan gambar kita harus membuat sebuah direktori dengan nama yang sama dengan judul artikel kita dan membuat sebuah file index.md dan meletakkan file gambar yang akan kita tampilkan di dalam direktori tersebut. Misal : kita ingin membuat artikel berjudul "mengenal varian nasi pecel" yang pada artikel tadi akan menampilkan file "pecel.jpg", maka kita harus membuat directory "content/posts/mengenal-varian-nasi-pecel/". Lantas membuat sebuah file index.md dan memastikan ada file "pecel.jpg" di dalamnya. Nah, pada file index.md kita bisa isi dengan sintaks :   
`![gambar nasi pecel](pecel.jpg)`.   
Agak ribet ya?. Emang...
